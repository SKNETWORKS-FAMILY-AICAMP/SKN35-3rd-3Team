# SKN35-3rd-3Team

## 데이터 인계 후 첫 실행

Python 3.12 이상과 uv가 설치된 환경에서 프로젝트 루트로 이동한 뒤 의존성을 설치합니다. 원본·정제·청크와 검토 기록을 함께 전달받아야 저장된 스냅샷을 검증할 수 있습니다.

```bash
uv sync --locked
uv run python -m unittest discover -s src/scripts/tests -t . -p "test*_pmh.py"
```

위 테스트는 수집 API를 호출하지 않으며 `LAW_API_OC` 없이 실행할 수 있습니다. 의존성을 처음 설치할 때는 네트워크가 필요할 수 있습니다. 새 법령·판례·행정규칙 수집에는 프로젝트 루트의 로컬 `.env` 또는 환경변수에 `LAW_API_OC`를 설정합니다. 실제 인증값은 커밋하거나 문서에 기록하지 않습니다.

```dotenv
LAW_API_OC=<발급받은_OC_값>
```

[데이터 인계서](docs/데이터_인계서_pmh.md)에 파일 위치·재생성 순서·필드 사용 규칙·검증 범위가 정리되어 있습니다. 처음에는 테스트로 인계받은 스냅샷을 확인하고, 갱신이 필요할 때 정제·청크 생성 명령을 실행합니다.

`embedding_text`는 임베딩 입력입니다. `search_passages`와 그 안의 `search_text`는 로컬 BM25 점수용 구간·표현이며 원문을 대체하지 않습니다. `required_context_unit_ids`는 청크 ID가 아닌 원문 단위 ID 목록입니다. 대상 청크의 `unit_id`로 연결해 관련 본문을 함께 확인하고 출처·적용 시점·경고를 보존합니다.

## 자료 보강 재개 현황

사용자의 재개 요청에 따라 방문판매법 시행령·시행규칙, 최저임금법 시행규칙, 단순노무직종 근로자 지정 고시 4종을 수집·정제·청크에 반영했습니다. 법령은 총 16종이며 검색용 청크는 총 3,793개입니다. 삭제·이동된 별표는 원문·PDF와 제외 사유를 보존하며, 별지 작성용 서식은 참고용으로 보존하고 기본 검색에서 제외합니다.

현재 내용 검토의 보완 필요 13문항과 원문 적용 보류 1문항은 남아 있습니다. 새 자료를 확보했다는 이유만으로 완료로 변경하지 않습니다. 방문판매법 관련 사례 당시 구법 대조, 최저임금 시행규칙의 원문 이미지·대체문자 및 실제 업무의 직업분류·급여 항목 대조, 나머지 분야의 자료 보강은 후속 작업입니다.

후속 보강은 질문별 원문 부족·정제 누락·검색 미적중 구분 → 필요한 원문 수집 → 정제·청크 반영 → 재검증 → 인계 문서 갱신 순서로 진행합니다. 코드 수정은 파일 목록을 먼저 제시하고 사용자 확인 후 진행하며, 새 테스트 파일 이름은 `_pmh.py`로 끝나게 합니다.

## 데이터 스크립트와 검증

소비자분쟁해결기준은 일반 조문과 체육시설업·택배 및 퀵서비스업·인터넷쇼핑몰업 기준 외에 별표 Ⅲ(품목별 품질보증기간·부품보유기간), 별표 Ⅳ(품목별 내용연수표)를 정제·청크에 반영합니다. 추가 별표는 조건·비고를 포함한 XML 본문 전체를 각각 한 청크로 보존하며, 출처·원문 위치·표 대조 필요 경고를 기록합니다. 임베딩 전에 큰 표의 토큰 제한을 확인해야 합니다. `raw` 원본은 변경하지 않습니다.

로컬 BM25 통합 검색은 문서 버전당 최대 2개 청크를 반환합니다. 긴 표의 본문 구간과 HWPX의 실제 셀 문자를 점수 계산에 사용하되, 반환·임베딩용 전체 원문은 보존합니다. `matched_span`은 점수에 사용한 본문 위치이며 표의 독립된 계산 근거가 아닙니다. 당사자 주장은 점수 0.6배로 보조하고 역할·출처·원문 경고를 함께 반환합니다. 헬스장/체력단련장, 환불/환급 용어 확장은 검색에만 사용합니다.

소비자 12문항·분야별 45문항 보고서는 같은 데이터에 기존 검색(문서당 1개)과 개선 검색을 적용해 비교합니다. 개선·하락 질문을 모두 기록하며, 원문 자료 충분성을 검색 적중률로 판정하지 않습니다. 품질보증 질문에는 별표 Ⅲ·Ⅳ를 추가 검토했지만 구매일 증빙과 표 대조가 남아 부분 확보 상태입니다. 실제 임베딩·Qdrant·LLM 검색 및 답변 품질 검증은 별도 작업입니다.

`src/scripts/`에는 수집·전처리·청크 실행 스크립트를, `src/scripts/tests/`에는 `test_*_pmh.py` 검증 파일을 보관합니다. 아래 명령은 프로젝트 루트에서 실행합니다.

전체 테스트:

```bash
uv run python -m unittest discover -s src/scripts/tests -t . -p "test*_pmh.py"
```

개별 테스트 예시:

```bash
uv run python -m unittest src.scripts.tests.test_preprocess_guides_pmh
```

검색 평가 보고서 생성·갱신(BM25 기반이며 임베딩·LLM 평가가 아닙니다):

```bash
uv run python -m src.scripts.tests.test_precedent_retrieval_pmh
uv run python -m src.scripts.tests.test_consumer_coverage_pmh
```

검색 평가 모듈은 직접 실행하면 보고서를 갱신하고, 전체 테스트에서는 저장된 데이터와 결과를 검증합니다. 소비자 검색 평가는 같은 테스트 패키지의 판례 평가 모듈에서 BM25 코드를 가져옵니다.

별표 Ⅱ 중 귀금속·보석 및 전자제품·사무용기기를 조건·연속 표·비고와 함께 추가 정제했습니다. 전체 품목 확보나 개인 간 중고거래 적용을 뜻하지 않습니다. 민법 제140·141조와 근로기준법 시행령 제7조의2도 기존 수집본에서 근거 목록에 연결합니다.

헬스장·필라테스 HWPX 환급 표 3개는 셀 좌표와 병합 범위를 검증하여 해지 주체·이용 전후·수식·공통 정의를 함께 기록합니다. 행별 검색 표현은 조건·환급 수식·생활 표현 별칭(환불 계산/환급금 계산)으로 구성하고 공통 정의는 전체 원문과 표 메타데이터에 보존합니다. 로컬 BM25 평가에서 본문 토큰 비중은 1, 출처 헤더는 0.5입니다. 검색 표현과 별칭은 점수 계산에만 사용하며 원문을 대체하거나 환급액을 계산하지 않습니다. 검색 보고서의 `preprocessing_baseline`은 수정 전 선정 근거를 고정해 누적 비교에 사용합니다. `search_refinement_baseline`은 이번 검색 표현·헤더 가중치 수정 직전의 선정 근거를 고정해 별도로 비교합니다. 임베딩·Qdrant 검색 품질 평가는 별도입니다.

우선 부족 원문 7종을 보강했습니다. 법령은 방문판매법·전자상거래법 시행령·최저임금법·최저임금법 시행령·주택임대차보호법 시행령을 추가했으며 이후 시행령·시행규칙 3종을 더 확보하여 현재 총 16종입니다. 고시는 계속거래 환급 산정기준과 2026년 적용 최저임금 고시를 추가했습니다. 최저임금 고시는 API 조문이 비어 있어 공식 첨부 PDF의 전문·표·페이지·해시 및 `valid_from`/`valid_until`을 연결합니다.

최저임금법 제6조 청크의 `required_context_unit_ids`는 본칙 비율을 수정하는 부칙을 가리킵니다. 해당 연도 산입범위를 본칙만으로 계산하지 마세요. 주택임대차 시행령의 현재 지역별 기준과 과거 담보권 시점별 적용도 구분해야 합니다. 이번에 위임 규정·시행규칙·직종 고시를 추가 확보했습니다. 과거 적용 버전·실제 직업분류·원문 이미지 대조 및 신고·폐업 등 공식 안내는 분야 보고서에 남은 보강 항목으로 기록합니다.

특정 소비자 자료만 수집하려면 아래 명령을 사용합니다. 이전 수집 기록과 기존 원본을 유지하며 새 출처는 manifest에 먼저 등록합니다.

```bash
uv run python src/scripts/collect_consumer_sources.py --source-id continual_contract_refund --source-id minimum_wage_2026
```

분야 보고서의 `source_supplement_comparison`은 이번 원문 보강 직전 근거 ID를 고정한 검색 비교입니다. 새 근거가 추가된 현재 평가 결과와 구분하며 하락한 질문도 기록합니다.

단순노무직종 고시 재수집: `uv run python src/scripts/collect_consumer_sources.py --source-id minimum_wage_simple_labor`. 법령 3종은 `collect_laws.py`의 `--name`을 반복 지정해 수집합니다. `delegated_source_comparison`은 이번 4종 보강 직전 선정 근거 ID를 고정한 비교이며 새 근거 연결로 평가가 자동 상승하는 효과와 구분합니다. 최저임금 시행규칙 제2조의 원문 이미지 태그·대체문자와 삭제된 별표1·2의 상태를 보존합니다.
