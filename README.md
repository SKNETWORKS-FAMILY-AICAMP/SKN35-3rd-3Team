# SKN35-3rd-3Team

## 데이터 스크립트와 검증

소비자분쟁해결기준은 일반 조문과 체육시설업·택배 및 퀵서비스업·인터넷쇼핑몰업 기준 외에 별표 Ⅲ(품목별 품질보증기간·부품보유기간), 별표 Ⅳ(품목별 내용연수표)를 정제·청크에 반영합니다. 추가 별표는 조건·비고를 포함한 XML 본문 전체를 각각 한 청크로 보존하며, 출처·원문 위치·표 대조 필요 경고를 기록합니다. 임베딩 전에 큰 표의 토큰 제한을 확인해야 합니다. `raw` 원본은 변경하지 않습니다.

로컬 BM25 통합 검색은 문서 버전당 최대 2개 청크를 반환합니다. 긴 표의 본문 구간과 HWPX의 실제 셀 문자를 점수 계산에 사용하되, 반환·임베딩용 전체 원문은 보존합니다. `matched_span`은 점수에 사용한 본문 위치이며 표의 독립된 계산 근거가 아닙니다. 당사자 주장은 점수 0.6배로 보조하고 역할·출처·원문 경고를 함께 반환합니다. 헬스장/체력단련장, 환불/환급 용어 확장은 검색에만 사용합니다.

소비자 12문항·분야별 45문항 보고서는 같은 데이터에 기존 검색(문서당 1개)과 개선 검색을 적용해 비교합니다. 개선·하락 질문을 모두 기록하며, 원문 자료 충분성을 검색 적중률로 판정하지 않습니다. 품질보증 질문에는 별표 Ⅲ·Ⅳ를 추가 검토했지만 구매일 증빙과 표 대조가 남아 부분 확보 상태입니다. 실제 임베딩·Qdrant·LLM 검색 및 답변 품질 검증은 별도 작업입니다.

`src/Scripts/`에는 수집·전처리·청크 실행 스크립트를, `src/Scripts/tests/`에는 `test_*_pmh.py` 검증 파일을 보관합니다. 아래 명령은 프로젝트 루트에서 실행합니다.

전체 테스트:

```bash
uv run python -m unittest discover -s src/Scripts/tests -t . -p "test*_pmh.py"
```

개별 테스트 예시:

```bash
uv run python -m unittest src.Scripts.tests.test_preprocess_guides_pmh
```

검색 평가 보고서 생성·갱신(BM25 기반이며 임베딩·LLM 평가가 아닙니다):

```bash
uv run python -m src.Scripts.tests.test_precedent_retrieval_pmh
uv run python -m src.Scripts.tests.test_consumer_coverage_pmh
```

검색 평가 모듈은 직접 실행하면 보고서를 갱신하고, 전체 테스트에서는 저장된 데이터와 결과를 검증합니다. 소비자 검색 평가는 같은 테스트 패키지의 판례 평가 모듈에서 BM25 코드를 가져옵니다.

별표 Ⅱ 중 귀금속·보석 및 전자제품·사무용기기를 조건·연속 표·비고와 함께 추가 정제했습니다. 전체 품목 확보나 개인 간 중고거래 적용을 뜻하지 않습니다. 민법 제140·141조와 근로기준법 시행령 제7조의2도 기존 수집본에서 근거 목록에 연결합니다.

헬스장·필라테스 HWPX 환급 표 3개는 셀 좌표와 병합 범위를 검증하여 해지 주체·이용 전후·수식·공통 정의를 함께 기록합니다. 행별 검색 표현과 생활 표현 별칭은 점수 계산에만 사용하며 원문을 대체하거나 환급액을 계산하지 않습니다. 검색 보고서의 `preprocessing_baseline`은 수정 전 선정 근거를 고정해 전처리 전후 비교에 사용합니다.
