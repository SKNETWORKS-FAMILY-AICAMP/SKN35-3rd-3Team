- **온라인 쇼핑 환불 / shopping_custom**: 전자상거래법 시행령의 주문제작 예외 조항 원문 보강

- **헬스장·필라테스 환불 / fitness_closed**: 폐업 피해구제·카드 결제 관련 공식 절차 안내 보강

- **보증금 반환 / deposit_small**: 주택임대차보호법 시행령과 필요한 과거 버전·부칙 보강
- **보증금 반환 / deposit_delay**: 소송촉진 관련 법·시행령과 반환 지연 직접 사례 검토
- **보증금 반환 / deposit_restore**: 통상손모·원상복구비 공제의 직접 사례와 공식 안내 보강
- **보증금 반환 / deposit_auction**: 민사집행법·규칙 관련 조문과 배당 신청 공식 안내 보강

- **소비자 피해 / consumer_mediation**: 소비자기본법과 KCA 피해구제·조정 신청 공식 안내 보강
- **소비자 피해 / consumer_repeat**: 서비스 대상 품목 확정 후 나머지 품목의 원본 정제 확대 및 공식 별표 대조
- **소비자 피해 / consumer_warranty**: 일반적 해결기준·구매일 증빙 안내 보강 및 별표 문자·병합 관계 대조
