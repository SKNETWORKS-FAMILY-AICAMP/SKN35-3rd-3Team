# LAW:MATE UI

다운로드한 Figma Make의 `App.tsx`를 참고한 Python / Streamlit 구현입니다.
프로젝트 루트에서 실행합니다.

```powershell
.venv/Scripts/python.exe -m streamlit run main.py
```

- `Chat.py`: 세션 초기화, 이미지 변환, 기존 LangGraph 상담 연결
- `views.py`: 공통 탐색, 상담 목록, 채팅, RAG 진행 패널, 분석 결과, 자료 상세, 이용 안내. 영역별로 함수를 나누며 화면 관련 처리를 담당합니다.
- `conversation_history.py`: 첫 질문 추출, 키워드 기반 분야 분류, 날짜별·분야별 상담 기록 묶기
- `progress.py`: 실제 그래프 노드 이벤트를 네 단계 진행 상태로 변환. 재검색·오류·답변 보류도 구분합니다.
- `loading.py`: 로딩 중 사용하는 기포·스켈레톤 그래픽. 안내 문구는 `Chat.py`의 기본 텍스트 위젯에서 표시합니다.
- `pdf_utils.py`: 기존 PDF → 이미지 변환 처리
- 루트 `.streamlit/config.toml`: 차콜 네이비·샴페인 골드 테마 및 한글 폰트
- `styles.css`: 공통 페이지 구조, 이용 안내, 분석 결과, 자료 상세 레이아웃
- `chat.css`: 상담 탭의 사이드바, 메시지 스크롤 영역, RAG 패널 레이아웃
- `palette.css`: 공통 강조색, 버튼 인터랙션, 진행 단계 아이콘
- `dark.css`: 기본 다크 화면. 딥 네이비 배경·차콜 카드·골드 버튼 테두리로 구분합니다.
- `page_navigation.py` 및 `.css`·`.js`: 고정 헤더와 페이지 스크롤에 반응하는 Top 버튼. 채팅 내부 스크롤과 구분합니다.

CSS는 `styles.css` → 상담 화면에서만 `chat.css` → `palette.css` → `dark.css` → `page_navigation.css` 순으로 적용합니다.
앞의 레이아웃에 브랜드 색상과 다크 테마를 덮어쓰므로 순서를 유지해야 합니다.
위젯 키는 CSS 선택자 및 세션 상태와 연결되어 있어 이름을 바꿀 때 함께 확인해야 합니다.
삭제된 홈 화면과 게스트 프로필의 CSS는 제거했습니다.

접속하면 AI 법률상담 화면이 바로 열립니다. 상담 입력창에서 질문과 이미지를 함께 보낼 수 있습니다.
상담 기록은 현재 세션에서 복원할 수 있으며 새 상담은 별도 thread ID를 사용합니다.
백엔드는 최초 질문 제출 시 초기화하므로 초기 화면을 확인할 때 API 연결이 필요하지 않습니다.

원본의 샘플 신뢰도, 상담 통계, 판례 번호를 실제 데이터처럼 표시하지 않습니다.
분석 화면은 백엔드 답변과 인용 구조 검사를 통과한 출처를 사용합니다.
`판례·법령 검색` 메뉴는 현재 상담의 분석 결과를 표시하며 독립 검색 기능은 연결되지 않았습니다.
상세 화면은 반환된 근거 본문을 표시합니다. 로그인과 영구 기록 저장은 구현 범위에 포함하지 않습니다.

Streamlit 기본 위젯과 반응형 컬럼으로 옮겼으므로 원본 React 화면과 픽셀 단위로 동일하지 않습니다.
